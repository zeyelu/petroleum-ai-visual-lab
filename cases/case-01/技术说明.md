# 修井方案神经网络实验室：实现说明

版本：3.0.0。日期：2026-10-28。独立案例 id：`workover-neural-lab`。对应场景：`wo1`。

## 1. 相比旧版的实质变化

旧版用知识关系、相似案例和人工效用权重产生推荐，没有训练神经网络。新版保留设备和证据约束，加入真实多任务 MLP，学习井况、候选路径与两个结果之间的关系。模型实际执行反向传播和 Adam 更新；默认权重为预先训练所得，不是手填预测值。

“专业背景—案例流程—案例演示”结构保持不变。演示内部有方案实验、训练与验证、数据档案三个视图。原始版本和上一版可视化增强版文件均保留，新版在独立目录构建。

本例不实现图神经网络、孪生网络、大语言模型、图像识别或施工参数优化。教师原门户方法词表没有通用监督神经网络标签，因此清单使用已有的 `kg` 标签表达知识约束与案例推理，标题和正文明确实际的多任务 MLP。未冒用 CV 或时序标签。

## 2. 专业问题、输出与约束

三类故障：砂卡/砂堵、结垢、套管损伤。六条候选路径依次为连续油管清砂、起出管柱检修、化学清垢、机械清垢、检测后局部修复评估、补充检测与重新评估。

前五条属于“处理与评估”，最后一条属于“补充信息”。套管损伤的两条路径分别显示在两个组，不给两组建立总排名。所有“完成”指本路径定义的目标，不自动等同修复成功、恢复产量或完整性验收。

硬约束在模型预测前检查：

| 路径 | 必须满足的教学前提 |
|---|---|
| 清砂 | 故障匹配；连续油管设备可用 |
| 管柱检修 | 故障匹配；修井机可用 |
| 化学清垢 | 故障匹配；连续油管设备可用；相容性已确认 |
| 机械清垢 | 故障匹配；修井机可用 |
| 局部修复评估 | 故障匹配；检测设备和修井机可用；损伤诊断已确认 |
| 补充检测 | 故障匹配；检测设备可用 |

未勾选是未确认或不可用。排除的路径不显示预测，也不会在导出报告中带入推荐预测。以上仅为教学条件，不是完整施工审核。

## 3. 数据生成与划分

固定 LCG 随机种子 231028。随机更新为 `(1664525 × seed + 1013904223) mod 2^32`，返回 seed / 2^32。井编号 1–1500；先用 Fisher–Yates 打乱编号，前 900 口为训练集，随后 300 口验证，最后 300 口测试。之后才为每井展开两条对应故障的候选记录。

因此训练/验证/测试分别是 1800/600/600 条；同一口井绝不跨集合。同井两条结果存在相关性，统计独立单位仍是井。

故障按井索引循环分配 sand/scale/casing；井深 `round((1200+3000U)/10)×10` m，井斜 `round(70U)` 度，程度 `1+floor(3U)`。定义 `d=(depth−1200)/3000`、`a=angle/70`、`s=severity−1`。

工时公式：

```
T = base × (0.62 + 0.44d + 0.20a + 0.23s + 0.23da + I_even × 0.12sa) × exp(ε)
ε = 0.14 × (U1+U2+U3−1.5) + well_noise
well_noise = 0.10 × (U4+U5+U6−1.5)
```

`well_noise` 在同井两条记录间共享；其他随机扰动每条独立抽取。`I_even` 在零基路径索引 0、2、4 时为 1。六条路径基础工时依次为 22、39、18、32、48、14 小时。最终工时保留两位小数。

完成标签：`p = sigmoid(logit)`，再按 `U < p` 生成 0/1。六条 logit 分别为：

```
清砂：2.70 − 1.05s − 0.55d − 0.65a − 0.60da
管柱检修：2.25 − 0.35s − 0.30d − 0.30a
化学清垢：2.80 − 0.95s − 0.40d − 0.60a − 0.50as
机械清垢：2.35 − 0.40s − 0.30d − 0.35a
局部修复评估：2.35 − 0.65s − 0.60d − 0.65a
补充检测：2.65 − 0.25s − 0.20d − 0.20a
```

网络只接收抽样后的 0/1 标签，不接收这些概率或公式。系数为教学设定；每口井不同路径的结果是模拟反事实，不是从真实干预对照中估计的因果效应。

每条记录包含 id、well、split、fault、depth、angle、severity、plan、completed、hours。设备和确认状态未放入训练数据：训练标签解释为该路径前提已满足时的结果，部署时以硬约束单独处理。

## 4. 神经网络与真实训练

输入共 12 维：3 个故障 one-hot，6 个路径 one-hot，3 个标准化数值特征（井深、井斜、程度）。数值均值与总体标准差仅由训练集计算。输出回归目标也仅用训练集对数工时的均值与标准差进行标准化。

默认结构：12 → Dense(24, ReLU) → Dense(12, ReLU) → 分类头 Dense(1, Sigmoid) 与回归头 Dense(1, Linear)。第一层可切换为 12/24/48。默认共 638 个可训练参数。

损失：`BCE(y, p) + 0.5 × MSE(z_log_time, z_hat)`。回归损失以自定义损失函数显式乘 0.5，不依赖未支持的配置字段。

优化器 Adam，学习率 0.006；batchSize=64，固定样本顺序；GlorotUniform 固定种子 2301/2302/2303/2304 对应四个 Dense 层。TensorFlow.js 4.22.0 CPU 后端执行训练，不需 GPU、后端或 API。

默认训练 90 轮，以验证总损失最低轮次选择权重，本次为第 6 轮。网页允许重新训练，或停止并保留已完成轮次中的验证最优权重。刷新恢复默认模型；导出 JSON 保存本次模型。

预测工时：`exp(z_hat × σ_train + μ_train)`。由于学习的是对数工时，这更接近条件中位数/几何尺度预测，不宣称为严格条件算术均值；未建立预测区间。前向实现的指数输入有数值保护截断 [-5,10]，正常教学范围内未触发。

## 5. 基线、指标与默认测试结果

案例推理基线使用同一新版训练库。只取同路径 15 个近邻，距离为三个训练标准化特征差的均方根，权重与 `1/(0.2+distance)^2` 成正比。分类输出为加权完成比例，工时为加权算术均值。路径均值基线不看井况，只看同路径训练记录均值。

| 模型 | Brier，越低越好 | 工时 MAE，越低越好 |
|---|---:|---:|
| 多任务神经网络 | 0.147834 | 2.827431 h |
| 同数据案例推理 | 0.169143 | 2.719607 h |
| 路径均值 | 0.161938 | 7.707440 h |

Brier 为 `mean((p−y)^2)`，MAE 为 `mean(abs(T_hat−T))`。本轮网络完成预测更好，但近邻的工时误差更小。网页动态计算并如实展示，不隐藏基线优势。

校准图固定分为 [0,.2)、[.2,.4)、[.4,.6)、[.6,.8)、[.8,1] 五箱，按箱内平均预测与实际完成比例画点。空箱不绘制，每点提示样本数。测试可见后反复调参属于课堂探索，不能再称严格盲评。

旧版 72 条记录仍可在“历史证据”折叠区域查看，但其生成机制不同，不与新版测试误差合并。

## 6. 排序、解释与可视化

同组效用：`100 × [(1−α)p + α×clip(1−T/150,0,1)]`。α 来自工时偏好，150 h 为教学参考尺度。效用不等于概率，不参加训练；调整偏好不会改变网络原始预测。

1. 概念剖面：位置对应套管、油管与故障，明确非比例示意。
2. 流程节点：分别展示专业任务、分组数据、学习结构、验证、约束与解释。
3. 候选散点：位置编码工时与完成可能性，文字标出路径，点击与证据联动。
4. 训练曲线：共享纵轴比较训练和验证损失，标记验证最优轮次。
5. 误差散点：实际工时与预测工时；对角线提供参照。
6. 校准图：检查高概率是否对应较高完成比例。
7. 敏感性曲线：一次改变一个井况特征，其他固定；概率纵轴固定 0–100%，工时从 0 起，训练范围外以灰色标示。
8. 替换条形：井深和井斜替换为训练均值，程度替换为 2，显示“替换后减当前”的概率百分点。不是 SHAP，也不是因果效应。
9. 激活图：方块对应真实节点；隐藏层激活 0–4 同色阶，超过上限饱和。连线只表示结构。输入正负数以不同颜色显示，精确值可悬停/聚焦读取。
10. 历史表格：近邻距离、井况差异、结果和时间；可导出全部原始字段。

手机使用图形横向滑动保持标签可读；颜色以绿色、灰蓝和赭色区分模型，状态同时给出文字。表单有显式标签，图形带标题，候选点可键盘操作。
