打开 index.html 即可。建议先读专业背景和案例流程，再进入案例演示。所有依赖和预训练权重在本地，运行无需联网，无后端，也不含视频。

导入老师门户：解压单案例 ZIP，使用“添加案例”选择整个本文件夹，校验并添加。case.json 在根目录，id=workover-quantile-lab，sceneId=wo5。同一场景存在多个案例时，门户可能优先显示最后导入的案例。

栏目：专业背景 / 案例流程 / 案例演示。演示内含交互分析、真实训练与检验、数据档案，可导出完整模拟数据和带模型参数的分析快照。训练仅保存在当前页面，刷新恢复默认预训练模型；离线性能取决于设备。

这是结构化回归，不包装成时序 LSTM。六工序点预测可以相加，六工序分位数不能相加充当总分位。资源是固定配置换算，不是最优排班或人员数量推荐。

这是原版之外的新目录，原始案例与此前增强版不变。案例 05 的 baseline.js 保留原算法；model.js 实现新模型与生成器；pretrained.js 保存权重、损失历史及默认测试结果。vendor 为离线 TensorFlow.js 及许可证。不要删除这些依赖。

门户方法标签沿用其支持的 kg/cv/ts 分类；实际模型以本案例说明为准，案例5的 ts 是门户广义预测归类，并不表示使用时序网络。

全部数据、工具规格与参数为教学模拟，非现场工程依据。
