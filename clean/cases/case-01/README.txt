修井作业方案智能推荐：知识约束与多任务神经网络
独立新版 v3.0.0 / 2026-10-28 / sceneId: wo1 / id: workover-neural-lab

【打开网页】
解压后双击 index.html；也可直接打开 demo/index.html。
请保留整个目录，不要只复制 HTML。CSS、JavaScript、预训练权重与 TensorFlow.js 都是网站源代码/运行依赖的一部分。
所有计算均在浏览器本地执行，默认不需要网络、服务器或 API Key。外部参考链接需联网阅读。

【添加到老师的门户】
1. 将“修井-修井作业方案智能推荐.zip”解压。
2. 打开原门户，点击“＋ 添加案例”。
3. 选择或拖入解压后的“修井-修井作业方案智能推荐”整个文件夹。
4. 校验后添加；不要把 ZIP 本身当作文件夹导入。
5. 案例绑定“修井 → 修井作业方案智能推荐”，包含专业背景、案例流程、案例演示。
新版使用独立案例 id，不会删除旧版案例。门户同一场景默认显示后导入的案例，这是原门户机制；旧案例仍保存在案例库。

【推荐体验顺序】
1. 专业背景：切换砂卡、结垢、套管损伤，观察井筒剖面。
2. 案例流程：逐个点击 6 个节点，看懂数据划分、网络训练和约束检查。
3. 案例演示 / 方案实验：调整井深和程度，比较候选；取消设备或确认条件，观察路径被排除。
4. 分别查看历史证据、敏感性、网络内部；这些图形使用当前模型的真实结果。
5. 训练与验证：比较神经网络、案例推理、路径均值；重新训练并观察验证损失是否回升。
6. 数据档案：筛选记录、阅读生成公式、导出 3000 条 CSV；分析快照可导出完整权重和测试结果。

【技术边界】
本案例使用真实训练的多任务 MLP：12 维输入 → 24 个 ReLU → 12 个 ReLU → 完成分类头/工时回归头。
可在浏览器切换第一隐藏层 12/24/48 个神经元，并训练 20/40/90/120 轮。
没有使用 LLM、CNN、GNN 或生产级工程优化器。文本入口仅为限定词表提取。
全部 1500 口井、3000 条记录都是教学模拟。生成公式是教学设定，不能当作行业统计。
设备、相容性和诊断是硬约束；神经网络不会自动替代这些确认。
补充检测与处理评估分组。完成某路径目标不等于恢复生产或通过工程验收。
重新训练的结果存于当前页面内存；刷新会恢复预训练模型。需要保存时请导出分析快照。
手机图形支持横向滑动以保留文字可读性；桌面端更适合完整课堂演示。

【文件说明】
case.json：老师门户的案例清单与背景、流程正文。
index.html：独立网站入口。
demo/index.html：完整网站。
demo/experiment.html：门户的演示入口，默认进入方案实验。
demo/app.js、style.css、content.js：交互、排版与教学内容。
demo/model.js：数据生成、特征编码、真实训练、预测、近邻与指标计算。
demo/pretrained.js：随包交付的权重、标准化参数和真实训练曲线。
demo/legacy.js：旧版计算器的独立副本，仅用于专业约束、井史提取及旧库参考。
demo/vendor/tf.min.js：TensorFlow.js 4.22.0，已随包离线提供。
技术说明.md：计算细节、指标、验证方法与数据边界。
