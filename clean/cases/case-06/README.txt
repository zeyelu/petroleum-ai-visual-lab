地震断层自动解释 · 公开数据版 1.0.0

一、独立运行
完整解压后，双击 index.html。含专业背景、案例流程、案例演示三个栏目。无需安装 Python、Node 或运行后端。所有网页依赖、数据、预训练权重均已嵌入。需要现代浏览器启用 JavaScript。

二、添加到老师门户
解压本案例 ZIP，点击“添加案例”，选择包含 case.json 的整个 case 文件夹，校验并添加。不要只选择 index.html。sceneId=s1，id=geo-public-fault-20261030。使用原门户 case.json/page 协议。
多个含神经网络的案例会超过浏览器 localStorage 容量；如门户提示空间不足，这是门户持久化限制，可先导出已有案例再清理，或使用随附独立页面。不要删除未备份的同学案例。

三、建议演示
1. 专业背景：拖动概念示意，解释一个石油术语。
2. 案例流程：点击步骤，看输入与输出。
3. 分析工作台：移动阈值，先看候选带的扩张，再看漏检和误检计数。点击图中一个点，四图联动定位。
4. 训练与检验：查看真实损失、网络结构和基线对比，可重新训练。
5. 数据档案：查看来源和数据分组，导出完整教学 JSON。
